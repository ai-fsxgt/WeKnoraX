# IM 集成开发

WeKnora 的 IM 集成由系统管理员统一配置第三方机器人，普通用户通过一次性绑定码把平台身份绑定到自己的 WeKnora 账号和工作空间。绑定后，用户可以在私聊中使用该工作空间内属于自己的知识库。

当前个人绑定支持企业微信、飞书、Lark、Slack、Telegram 和钉钉。微信和 QQ 机器人可由系统管理员配置，但尚未开放个人绑定；Mattermost 和云之家不在当前适配范围内。

## 使用流程

### 系统管理员

1. 在第三方平台创建应用或机器人并获取凭据。
2. 进入 **设置 → 系统管理 → IM 机器人** 创建全局机器人。
3. 配置接入模式、输出模式和凭据后启用机器人。
4. Webhook 模式还需把渠道回调地址配置到第三方平台。

### 普通用户

1. 进入 **设置 → 集成 → IM**，选择机器人和自己的工作空间。
2. 生成有效期为 5 分钟的一次性绑定码。
3. 私聊机器人并直接发送完整的 `WK-...` 绑定码。
4. 绑定成功后，在同一私聊中提问。

绑定不依赖 `/bind` 等命令。个人绑定当前只接受私聊，群聊消息不会进入问答流程。

## 权限与知识库范围

机器人配置不绑定用户、工作空间、Agent 或知识库。每条消息都根据平台验证后的发送者 ID 解析个人绑定，并检查以下状态：

- WeKnora 用户处于启用状态
- 用户仍是所选工作空间的有效成员
- 机器人和个人绑定仍然有效
- 知识库位于用户所选工作空间、不是临时知识库且支持快速问答

排队任务执行前和回复发送前会再次检查权限。解绑、退出工作空间或停用机器人后，未完成的结果不会继续发送。

## 支持的平台

| 平台 | 系统机器人配置 | 个人绑定 | 接入模式 |
|------|:-:|:-:|------|
| 企业微信 | ✅ | ✅ | WebSocket / Webhook |
| 飞书 | ✅ | ✅ | WebSocket / Webhook |
| Lark | ✅ | ✅ | WebSocket / Webhook |
| Slack | ✅ | ✅ | Socket Mode / Events API |
| Telegram | ✅ | ✅ | 长轮询 / Webhook |
| 钉钉 | ✅ | ✅ | Stream / Webhook |
| 微信 | ✅ | — | 长轮询 |
| QQ 机器人 | ✅ | — | WebSocket |

## 内置命令

| 命令 | 说明 |
|------|------|
| `/help` | 显示可用命令 |
| `/info` | 查看当前工作空间和知识库范围 |
| `/search` | 对绑定范围内的知识库执行混合检索 |
| `/stop` | 取消当前 QA 请求 |
| `/clear` | 清空当前对话记忆 |

文件和图片只作为当前问题的附件供模型理解，不会自动写入知识库。

## 架构设计

各平台实现统一的 `im.Adapter` 接口，通过 `AdapterFactory` 创建。平台适配器负责验签、解析消息和发送回复，统一的 IM Service 负责个人绑定、权限校验、会话、队列和快速问答。

详细的接入步骤、数据模型、API、消息流程与平台实现说明见 [IM 集成开发文档](../../IM集成开发文档.md)。
